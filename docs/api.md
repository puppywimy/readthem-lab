# API

이 프로젝트의 API 명세입니다.

## 도서

### 도서 순위 다건 조회

```text
GET /api/v1/books/rank?type={type}&size={size}
```

로그인 없이 호출할 수 있습니다. 페이징 없이 항상 상위 `size`권을 반환하며, 도서가 `size`권보다 적을 때만 덜 내려옵니다.

| 파라미터 | 기본값 | 설명 |
| --- | --- | --- |
| `type` | `""` | 정렬 기준. `views`, `rating`, 그 밖의 값(`reviewCount` 등) |
| `size` | `10` | 반환할 도서 수 |

| `type` | 정렬 기준 |
| --- | --- |
| `views` | 인기 도서. 아래 순서로 채웁니다. |
| `rating` | 평균 별점 내림차순, 같으면 운영 정보 `id` 내림차순 |
| 그 밖의 값 | 리뷰 수 내림차순, 같으면 운영 정보 `id` 내림차순 |

`rating`과 리뷰 수 순위에서 운영 정보(`book_operational`)가 있는 도서가 `size`권보다 적으면, 운영 정보가 없는 도서를 도서 `id` 내림차순으로 이어 붙입니다.

`views`는 다음 순서로 `size`권이 찰 때까지 채웁니다. 앞 단계에 들어간 도서는 뒤 단계에서 뺍니다.

1. 최근 60분 조회수 순 (Redis 분 단위 키 `viewCount:minute:*`). Redis 조회에 실패하면 건너뜁니다.
2. 누적 조회수 순 (DB `book_operational.view_count`). Redis `viewCount`에 쌓인 조회수를 `BookScheduler`가 5분마다(`prod` 프로필) 반영하므로 최대 5분 늦을 수 있습니다.
3. 운영 정보가 없는 도서, 도서 `id` 내림차순

응답은 도서 목록(`id`, `title`, `imgUrl`, `averageRating`)입니다.

### 도서 검색 다건 조회

```text
GET /api/v1/books/search?searchTerm={searchTerm}&page={page}&size={size}
```

로그인 없이 호출할 수 있습니다.

| 파라미터 | 기본값 | 허용 범위 | 설명 |
| --- | --- | --- | --- |
| `searchTerm` | 없음(필수) | 공백만으로 된 값 불가 | 검색어 |
| `page` | `0` | `0` 이상 | 0부터 시작하는 페이지 번호 |
| `size` | `10` | `1` ~ `50` | 한 페이지의 도서 수 |

허용 범위를 벗어나면 `400`(`resultCode` `400-1`)을 반환합니다.

FULLTEXT 검색(4단계, 제목·저자 중간 일치)을 실행할 자리가 1초 안에 나지 않거나 FULLTEXT 쿼리가 실패하면(메모리 상한 초과 등) 1~3단계(제목 완전 일치, 제목·저자 앞부분 일치) 결과만으로 응답합니다. 이때도 `200`이며 폴백 여부는 응답에 드러나지 않습니다.

응답은 도서 목록(`id`, `title`, `imgUrl`, `averageRating`)입니다.

### 도서 썸네일 지연 조회

```text
GET /api/v1/books/{id}/thumbnail
```

로그인 없이 호출할 수 있습니다. 도서에 표지 주소(`imgUrl`)가 없을 때 프론트가 호출하며, ISBN으로 카카오 책 검색 API를 조회해 썸네일 주소를 채웁니다. 도서 표지는 카카오 썸네일로 통일하므로 도서 수집 때는 표지 주소를 저장하지 않습니다.

| 상황 | 응답 |
| --- | --- |
| 카카오에 썸네일이 있음 | 썸네일 주소를 도서에 저장하고 `{"imgUrl": "<주소>"}`를 반환합니다. |
| 카카오에 썸네일이 없음 | 조회 이력(`img_url_fetched_at`)을 남기고 `{"imgUrl": ""}`를 반환합니다. 이후 호출은 `404`(`404-2`)입니다. |
| 카카오 호출 실패(타임아웃·오류·API 키 없음) | 이력을 남기지 않고 `{"imgUrl": ""}`를 반환합니다. 다음 호출 때 다시 조회합니다. |
| 이미 표지 주소가 있음 | `409`(`409-1`) |
| 도서가 없음 | `404`(`404-1`) |

관리자 도서 수정(`PUT /api/v1/books/{id}`)은 여전히 `imgUrl`을 받지만, 관리자 화면은 기존 값을 그대로 보냅니다.
