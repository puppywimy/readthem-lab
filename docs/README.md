# docs

이 프로젝트에 대한 모든 문서를 모아 둔 폴더입니다.

## 구조

```
docs
├── README.md                - docs 소개와 구조입니다.
├── api.md                   - API 명세입니다.
├── conventions.md           - 커밋 메시지, 개발 프로세스, 브랜치 규칙입니다.
├── design
│   ├── README.md            - 디자인 가이드라인 안내입니다.
│   ├── index.html           - 현재 화면을 옮긴 디자인 가이드라인입니다.
│   └── widget-sample.svg    - 가이드라인에 쓰는 위젯 샘플 이미지입니다.
├── erd.html                 - ERD입니다.
├── guardrails.md            - 절대 해서는 안 되는 것들의 목록입니다.
├── other_considerations.md  - 이미 논의가 끝나 결정된 내용입니다.
└── software_architecture.md - 백엔드 소프트웨어 아키텍처와 팀 컨벤션입니다.
```

ERD는 사람도 다이어그램을 쉽게 볼 수 있도록 HTML로 관리합니다.
