# Guardrails

이 프로젝트에서 절대 해서는 안 되는 것들의 목록입니다.

## DB 마이그레이션

- 적용된 마이그레이션 파일(`back/src/main/resources/db/migration/`)은 수정하지 않습니다. Flyway가 체크섬을 저장하므로 고치면 다음 기동이 실패합니다. 스키마 변경은 V2, V3 … 새 파일로만 합니다.
- 마이그레이션은 이전 버전 코드와 호환되게 작성합니다. 컬럼 삭제·이름 변경은 두 번의 배포로 나눕니다. Blue/Green 배포에서는 GREEN이 뜰 때 마이그레이션이 실행되고 그동안 BLUE가 이전 코드로 트래픽을 받습니다. 헬스체크 실패로 GREEN이 제거돼도 적용된 마이그레이션은 되돌려지지 않습니다.
