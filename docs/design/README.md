# 디자인 가이드라인

`index.html`은 현재 `front/` 화면을 옮긴 디자인 가이드라인입니다. 단, 홈 화면과 사이트 이름(Readthem Lab)은 새 디자인을 먼저 반영한 것으로 `front/`와 다릅니다. 디자인과 UI/UX를 보여주기 위한 용도이므로, API 연동이나 복잡한 기능은 여기서 구현하지 않습니다.

브라우저로 `index.html`을 바로 열면 됩니다. Tailwind, rough.js, 글꼴은 CDN에서 불러오므로 인터넷 연결이 필요합니다.

- 위쪽 막대에서 화면과 로그인 상태(비로그인, 회원, 관리자)를 바꿀 수 있습니다.
- `디자인 기준` 화면에 색상 토큰, 컴포넌트, 레이아웃, UX 규칙을 모았습니다.
- 도서, 리뷰, 회원은 샘플 데이터이고, 표지는 실제 표지 대신 만든 임시 이미지입니다. 홈 화면의 표지만 Open Library에서 불러온 원서 표지입니다.
- 홈 헤더의 `도서 검색`은 페이지 최상단으로, `독서 트렌드`와 `리뷰`는 각 섹션으로 이동합니다. `내 서재`는 로그인해야 보입니다.
- 홈 히어로 소개 문구의 `독서 트렌드`는 순위 섹션으로 이동하는 링크입니다.
- 홈 마지막 섹션은 `widget-sample.svg`로 위젯을 보여 주고, 비로그인 상태에서는 GitHub 로그인으로 이어집니다.
- 860px 이하에서는 헤더 메뉴가 로고 아래 줄로 내려오고, 순위 탭은 한 줄 가로 스크롤이 됩니다.
- `widget-sample.svg`는 `widget/`의 렌더러로 샘플 데이터를 그린 위젯 이미지입니다.

`front/`의 디자인을 바꾸면 이 문서도 함께 고칩니다. `index.html`의 CSS는 `front/src/app/globals.css`의 복사본이고, 마크업과 클래스는 `front/src/app`의 컴포넌트와 같습니다. 홈 화면 CSS는 예외로, `.home-a` 안에 따로 두었습니다.

## 새 디자인 시안

`index-a.html`, `index-b.html`, `index-c.html`은 메인 페이지 새 디자인 시안입니다. 기존 디자인과 무관하게 만들었습니다. A안을 `index.html` 홈 화면에 반영했고, `front/`에는 아직 반영하지 않았습니다.

| 파일 | 방향 | 특징 |
| --- | --- | --- |
| `index-a.html` | 표지 벽 | 표지가 흐르는 첫 화면, 탭 하나로 묶은 순위 |
| `index-b.html` | 서평지 | 리뷰가 헤드라인이 되는 명조 지면 |
| `index-c.html` | README | 마크다운 문법을 화면 요소로 쓰고, 검색은 Ctrl+K 팔레트 |

- 브라우저로 바로 열 수 있고, 글꼴, 아이콘, 표지를 불러오려면 인터넷 연결이 필요합니다.
- 도서 수치, 리뷰, 사용자명은 샘플 데이터입니다.
- 표지는 Open Library의 원서 표지이며, 불러오지 못하면 글자 표지로 대체됩니다.
