# 디자인 가이드라인

`index.html`은 Readthem Lab의 새 디자인 기준을 보여 주는 정적 프로토타입입니다. 홈, 도서 검색, 도서 상세, 마이페이지, 관리자, 회원가입(약관) 화면이 있고, `front/`에 반영되어 있습니다. API가 지원하지 않는 항목(저자·리뷰 수·조회수 표시, 전체 도서 목록, 상세 필터, 약관 동의 가입)은 `front/`에서 뺐습니다. 디자인과 UI/UX를 보여주기 위한 용도이므로, API 연동이나 복잡한 기능은 여기서 구현하지 않습니다.

브라우저로 `index.html`을 바로 열면 됩니다. 글꼴과 표지를 불러오려면 인터넷 연결이 필요합니다.

- 맨 위 검은 막대는 화면 이동용 패널입니다. 화면 이동, 로그인 상태(비로그인, 회원, 관리자), 화면 상태(기본, 비어 있음, 로딩)를 바꿀 수 있고, 실제 서비스에는 넣지 않습니다.
- 회원 서재와 오류 화면은 전용 시안이 없어, `front/`에서는 내 서재와 상태 메시지 스타일을 재사용합니다. 이전 디자인은 git 기록에서 볼 수 있습니다.
- 도서, 리뷰, 회원은 샘플 데이터입니다. 표지는 Open Library의 원서 표지이고, 불러오지 못하면 글자 표지로 대체됩니다.
- 색상 토큰과 레이아웃은 `.home-a` 안에 있습니다. 모서리는 표지 4px, 패널 16px, 상호작용 요소 pill입니다.
- 홈 헤더의 `도서 검색`은 페이지 최상단으로, `독서 트렌드`와 `리뷰`는 각 섹션으로 이동합니다. `내 서재`는 로그인해야 보이고, `관리자`는 관리자 계정에만 강조 표시로 보입니다.
- 860px 이하에서는 헤더 메뉴가 로고 아래 줄로 내려오고, 탭은 한 줄 가로 스크롤이 됩니다.
- `widget-sample.svg`는 위젯의 새 디자인 샘플입니다. 작성한 리뷰와 보고 싶어요한 책의 표지를 섞어 홈 표지 벽처럼 위아래로 흐르게 하고, 다른 정보는 넣지 않습니다. README의 `<img>`에서도 보이도록 표지를 파일 안에 내장했고, `widget/` 렌더러에는 아직 반영하지 않았습니다.
- 도서 검색의 상세 필터(태그, 최소 별점, 출간 연도)는 UI만 있고 결과에는 적용되지 않습니다. 860px 이하에서는 `상세 검색` 버튼으로 접힙니다.
- 도서 상세에서 좋아요가 가장 많은 리뷰에는 `베스트 리뷰` 배지를 붙입니다. 좋아요가 0개면 붙이지 않습니다. 베스트 리뷰는 고정이고, 정렬(최신순 기본, 인기순)은 그 아래 목록에만 적용됩니다.
- 회원가입은 GitHub 인증 뒤 신규 회원에게만 약관 동의를 받는 흐름을 가정했습니다. 약관 문구는 샘플이며 법률 검토가 필요합니다.
