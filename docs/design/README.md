# 디자인 가이드라인

`index.html`은 현재 `front/` 화면을 그대로 옮긴 디자인 가이드라인입니다. 디자인과 UI/UX를 보여주기 위한 용도이므로, API 연동이나 복잡한 기능은 여기서 구현하지 않습니다.

브라우저로 `index.html`을 바로 열면 됩니다. Tailwind, rough.js, 글꼴은 CDN에서 불러오므로 인터넷 연결이 필요합니다.

- 위쪽 막대에서 화면과 로그인 상태(비로그인, 회원, 관리자)를 바꿀 수 있습니다.
- `디자인 기준` 화면에 색상 토큰, 컴포넌트, 레이아웃, UX 규칙을 모았습니다.
- 도서, 리뷰, 회원은 샘플 데이터이고, 표지는 실제 표지 대신 만든 임시 이미지입니다.
- `widget-sample.svg`는 `widget/`의 렌더러로 샘플 데이터를 그린 위젯 이미지입니다.

`front/`의 디자인을 바꾸면 이 문서도 함께 고칩니다. `index.html`의 CSS는 `front/src/app/globals.css`의 복사본이고, 마크업과 클래스는 `front/src/app`의 컴포넌트와 같습니다.
